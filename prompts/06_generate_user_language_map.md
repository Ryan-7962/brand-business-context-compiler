# Prompt 06｜生成用户语言 ↔ 品牌术语映射

请建立用户真实问法和品牌术语/卖点/证据之间的桥接表。

本步骤属于产品知识母库的理解层，只帮助 AI 理解用户怎么说、品牌怎么说、应调用哪个 claim。第一阶段不生成完整 GEO brief。

## 字段

| 用户语言/搜索问法 | 用户真实意图 | 品牌术语 | 推荐产品/SKU/香型 | 应调用 Claim | 应调用证据 | 内容表达建议 | 风险提示 |
|---|---|---|---|---|---|---|---|

## 示例

- 去汗味 / 运动后汗味重 → NEOFRESH™ 异味控制技术 → 去汗味消费者实证。
- 洗完不假滑 / 易冲洗 → 一冲即净、不假滑消费者实证。
- 香味高级 / 像香水 → 香水级香氛、大师精油调香、香调结构。
- 敏感肌能不能用 → 温和亲肤、敏感肌适用消费者实证。

## 规则

- 用户语言要像真实搜索词，而不是品牌广告语。
- 每个映射必须落到具体 claim 或证据。
- 没有证据的映射标记为待确认。
- 不要在本步骤扩写成完整平台内容或投放 brief。
