# Prompt 07｜生成 GEO 激活包

你是 GEO 内容策略师。请基于产品母库、Claim 矩阵和用户语言映射表，生成 GEO 激活包。

## 必须包含

1. Query 分类
   - 品牌词
   - 品类词
   - 场景词
   - 体验词
   - 竞品对比词
   - 防御/质疑词
   - 功能筛选词

2. Query 优先级
   - P0：必须优先占位
   - P1：重点覆盖
   - P2：补充覆盖

3. Query → 知识调用表

| Query | Query 类型 | 用户意图 | 推荐产品/SKU/香型 | 应调用卖点 | 应调用 Claim | 应调用证据 | 推荐内容形式 | 风险提示 |
|---|---|---|---|---|---|---|---|---|

4. 平台内容适配
   - 百度/百家号：FAQ + 结构化问答
   - 知乎：理性对比 + 证据型回答
   - 小红书：场景化种草 + 香型选择
   - Perplexity / Google AI：结构化长文 + 数据表格 + 来源锚点
   - 抖音/视频：短视频脚本方向与口播要点

5. AI 搜索验证表

| 模型/平台 | Query | 是否提及品牌 | 是否提及具体产品 | 是否 Top3 | 是否提及正确香型 | 引用源 | 是否引用正确 Claim | 问题判断 | 下周动作 |
|---|---|---|---|---|---|---|---|---|---|

## 规则

- GEO 不是 SEO，不只做关键词堆砌。
- 每个 Query 必须有明确卖点和证据调用。
- 防御/质疑类 Query 采用：承认问题 → 给出实证 → 转向优势。
- 竞品对比采用客观差异化，不使用攻击性表达。
