# Anonymous Marketing Campaign Demo

这是一个完全虚构的营销活动方案 demo，用于展示 Brand Marketing Context Compiler 第一阶段默认产物。

场景设定：

- 资料类型：夏季品牌活动方案。
- 品牌：云杉生活，虚构品牌。
- 活动：夏日城市清爽节，虚构活动。
- 数据：全部为示例占位，不代表真实市场或客户数据。

建议查看：

- `outputs/03_marketing_semantic_transcript.md`：AI 可读语义转述。
- `outputs/08_review_pack.md`：品牌经理审核清单。
- `outputs/10_context_asset_index.md`：后续 GEO、PDP、拍摄、种草、销售等 Skill 可调用的上下文资产索引。
- `review/brand_review.html`：静态审核网页，由 CLI 生成。
