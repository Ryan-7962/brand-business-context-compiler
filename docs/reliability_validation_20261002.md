## 第二轮：当前交付与限制

- 6 份真实产品/营销资料，共 260 页/slide。WorkBuddy CLI 使用 DeepSeek V4.1 Flash 返回 260 条视觉记录；逐一校验锚点，无缺号、重复。不是 260 页语义完全准确的证明。
- 三份 PPTX 用本地 LibreOffice 导出，显式保留隐藏页。默认导出漏掉的 10 张隐藏页已补齐；153 张 PPTX 渲染图加 107 张 PDF 整页图均有返回。隐藏状态与讲者备注从原始 XML 提取。渲染不保证 PowerPoint 的原字体与版式。
- 形成六份知识页、批次索引、异常队列、中文本地 HTML 及逐页视觉 Markdown 候选；保留原始转写、原页和模型回执。原件及副本哈希未变。
- 主审查核对关键产品页、升级表、备案信息及研究设计。研究稿两轮不合格候选被拒绝；去除重复事实表输入后重新编译，恢复资料已有的研究样本与核心结论。不能以结构验证替代内容审查。
- 备案号与备案品名的误读已按高清原图纠正。仍有报告缩略图、表格数值归属及成分标签的未解决问题，单独保留在异常队列，不将其作为已确认业务事实。
- `verify-wiki` 通过。验收结论是「覆盖与结构通过、关键内容抽查通过、仍有局部语义缺口」，不是全批无误或 90% 准确率认证。
- 初始全页低置信度提示不作为使用者逐页确认要求；实际疑点先由 Agent 校准，仍无法判断的关键区域才需要原报告或更清楚的原页。
